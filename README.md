# Sing Coach

An AI-powered vocal analysis tool that analyzes your voice recording and provides feedback based on emotion, harmonics, and vocal characteristics rather than relying solely on a strict pitch grid.

### Try It Yourself

**[Launch Sing Coach](https://sing-coach.streamlit.app/)**

## Features

* **Audio Analysis** — Analyze an uploaded voice recording
* **AI Feedback** — Get vocal feedback powered by Gemini
* **Harmonic Analysis** — Looks beyond simple pitch tracking
* **Simple Uploading** — Upload a recording and get your analysis
